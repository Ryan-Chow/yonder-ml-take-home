# Ablation with uncertainty

Generated by `scripts/bootstrap_ablation.py`: 199 grouped-val images in 102 same-origin groups, 2000 paired **cluster** bootstrap resamples (whole groups drawn with replacement, because errors are correlated within a group; the same draw is applied to every arm). Predictions come from the deployment path (`src/infer.py`, conf >= 0.001). AP uses `src/apstats.py`, tested equal to Ultralytics' `compute_ap`. Each arm is a single training run (seed 0), so these intervals capture **val-set sampling noise only, not training-seed noise**. Seed noise would widen them further.
